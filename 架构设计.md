## 1. 项目目录结构
```text
src/
  pages/            ← 页面组件（Dashboard.tsx）
  components/       ← 通用组件（Card.tsx, Button.tsx）
  services/         ← API 封装（api.ts）
  hooks/            ← 自定义 Hook（useHealthCheck.ts）
  routes/           ← 路由配置（AppRoutes.tsx）
  types/            ← TypeScript 类型定义（可选，也可放在 services/）
  App.tsx           ← 根组件
  main.tsx          ← 入口
```
